# Security

Unreviewed custody prototype. Never use real funds. Deployment remains blocked; a second human reviewer must review authorization, token trust, per-circle accounting, rollback and indefinite lock risks before any funded test. Report vulnerabilities privately to the repository maintainer; do not publish seed phrases or personal details.

Members and payout order are immutable. Only member-authorized contributions enter the pot. Any caller may settle only after all listed members pay. There is no admin withdrawal. Malicious/frozen tokens, archival, missed contributions and public-wallet privacy remain risks.
